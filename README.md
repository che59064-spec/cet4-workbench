# 四级备考工作台（CET-4 Workbench）

大学英语四级（CET-4）全功能备考桌面应用：4544 词库背诵、听力/阅读专项、全真四部分模拟考试、写作 AI 批改、段落翻译、题库中心。纯前端 + Electron，数据全部保存在本地。

## ✨ 功能一览

- 📖 **单词本**：4544 词四级词库（英美音标 / 多义项 / 词组 / 双语例句）+ 卡片式背诵（键盘快捷键）/ 记忆状态 / 每日学习计时
- 🎧 **听力 · 阅读专项**：16 组听力 + 16 篇阅读（TTS 朗读 / 解析 / 正确率统计）
- 📝 **模拟考试（四部分全真结构）**：写作 + 听力（新闻/对话/短文 12 题）+ 阅读（选词填空 15 选 10 + 仔细阅读 10 题）+ 段落翻译，共 **710 分 / 425 过线 / 95 分钟**
  - 交卷即判客观题 → 错题解析；作文 **AI 按四级 15 分制多维批改**（字数/结构/句型/词汇/语法）；翻译对照参考译文自评
- ✍️ **写作中心**：18 个真题题型模板（框架/万能句型/范文/陷阱）、80 道写作题库（含审题思路）、素材宝典（40 组高级替换词、30 亮点句型、常见错误 TOP20）、写作实战（30 分钟计时 + 草稿 + 智能预评分）
- 🧩 **专项训练**：词汇精练 / 听力听写 / 翻译实战，程序化出题，每个专项**前 200 套内容不重复**，可无限续刷
- 🗂️ **题库中心**：真题文本一键转 JSON 导入、在线题库拉取、自动批量组卷（题库 16×16 可组合 1.4 万套）
- 🎨 **Mineradio 风格深色玻璃霓虹 UI**：毛玻璃卡片、漂浮光球、霓虹辉光

## 🚀 快速开始

```bash
# 国内网络建议先设置镜像
set ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/
npm config set registry https://registry.npmmirror.com

npm install
npm start        # 开发模式启动桌面应用
```

也可以直接用浏览器打开根目录 `index.html`（纯前端，无需 Node）。

## 📦 打包发布

```bash
npm run dist    # NSIS 安装包 → release/
npm run pack    # 免安装便携版 exe → release/
```

## 🧾 试卷导入格式

题库中心支持「文本自动转换」（粘贴网页真题文本 → 生成 JSON），也支持直接导入 JSON：

```json
{
  "title": "2026年6月模拟卷",
  "time": 3600,
  "listening": [{ "id": "L", "title": "短对话 · 购物", "audio": "原文文本(TTS) 或 audioUrl 真实音频",
    "questions": [{ "q": "问题", "options": ["A","B","C","D"], "answer": 1, "analysis": "解析" }] }],
  "reading": [{ "id": "R", "title": "文章标题", "paragraphs": ["段落1","段落2"],
    "questions": [{ "q": "问题", "options": ["A","B","C","D"], "answer": 0, "analysis": "解析" }] }]
}
```
